tinyBird emulates a Game Boy Advance in Rust. The same core drives a desktop app, this page, and the stream overlays — so a game reports the same live data wherever you run it.

Game addons

An addon reads live state out of the running game and publishes it through one schema, so the dashboard, the overlay, and any tool of yours see the same data. They are JSON, not code.

Pokémon FireRed / LeafGreen

Party, area encounters, active battle.

Final Fantasy Tactics Advance

Player name, every unit on the field by name with HP and MP, and which of them are yours.

Any other cartridge

Header, region, maker, checksum. This one claims every ROM and runs last, so a game nobody has written an addon for still shows something useful.
