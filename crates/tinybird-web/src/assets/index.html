Other ways to run the core

01

Desktop

cargo run --release

A native window with gamepads, save states and the add-on dashboard.

02

Headless

cargo run -p tinybird-runtime

JSON lines over stdin and stdout, for scripts, tests and the Python tools in examples/python.

03

Overlay

TINYBIRD_WEB_OVERLAY=1

Stream pages that read the desktop app's export. Off unless the server is started with that variable.
