tinyBird Web

Overlay control room for tinyBird streams.

Use the combined web UI to monitor everything together, then add the dedicated section URLs as separate OBS browser sources.

Open Combined Web UI Party OBS Source Area OBS Source Battle OBS Source

Run Order

1. Start the desktop app

Keep tinyBird running so it can refresh stream-data/current-game.json.

2. Start the web server

cargo run --release --bin tinybird-web

3. Monitor together

http://127.0.0.1:8877/overlay/full

OBS Sources

Add these as separate browser sources so each section can be positioned independently.

  • /overlay/party for the team cards
  • /overlay/area for route encounter info
  • /overlay/battle for active battle scout info
  • /overlay/full for the organized all-in-one view

Current APIs

  • /api/health for local status
  • /api/snapshot for the live export JSON
  • /sprites/:species_id for cached art
  • /overlay/:section for stream overlays
