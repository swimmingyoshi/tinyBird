One GBA core.
Three places to run it.

tinyBird emulates a Game Boy Advance in Rust. The same core drives a desktop app, this page, and the stream overlays — so a game reports the same live data wherever you run it.

Game addons

An addon reads live state out of the running game and publishes it through one schema, so the dashboard, the overlay, and any tool of yours see the same data.

Run it yourself

# Desktop
cargo run --release -- roms/game.gba

# This page, plus the overlay server
cargo build -p tinybird-wasm --target wasm32-unknown-unknown --release
cargo run -p tinybird-web

# Optional: point it at your asset vault
cp .env.example .env   # then set TINYBIRD_MEDIA_KEY
