tinyBird Web

Local overlay server for stream scenes, party tracking, and future battle tools.

This is the first web slice of tinyBird. It reads the desktop export, serves cached Pokemon artwork, and renders an OBS-friendly overlay page.

Open Overlay Preview OBS Browser Source Mode

Run Order

1. Start the desktop app

Keep tinyBird running so it can refresh stream-data/current-game.json.

2. Start the web server

cargo run -p tinybird-web

3. Add it to OBS

http://127.0.0.1:8877/overlay?transparent=1&layout=column

Current APIs

  • /api/health for local status
  • /api/snapshot for the live export JSON
  • /sprites/:species_id for cached art
  • /overlay for the stream layout
